# 16 Accounts Admin — новая админка

## Структура
1. **Режимы** — выбор между двумя режимами:
   - **🌐 Общий**: все аккаунты используют один список групп, один ИИ-промт и общие интервалы.
   - **👤 Личный**: каждый аккаунт использует собственные группы, ИИ-промт и интервалы.
2. **Аккаунты** — список всех 16 аккаунтов. Для каждого есть запуск/остановка, личный промт и личные группы.
3. **Доступ** — создание и удаление администраторов. Пароли хранятся в виде хэшей.

## Важно
- Первый администратор создаётся из `ADMIN_USERNAME` / `ADMIN_PASSWORD` при первом запуске, если `data/admins.json` ещё нет.
- После создания дополнительных админов их можно использовать независимо.
- `data/shared.json` хранит общий режим.
- `data/<account>.json` хранит личные настройки.
- Session strings не храните в коде или GitHub.

## Запуск
```bash
pip install -r requirements.txt
python userbot.py
```
