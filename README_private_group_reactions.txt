Что изменено

telegram_actions.py теперь отдельно обрабатывает приватные ссылки вида:
https://t.me/c/<ID>/<MESSAGE_ID>

Для таких ссылок реакция пытается получить InputPeer через get_input_entity(),
а если сущность не найдена в обычном кеше Telethon — ищет её среди диалогов
конкретного аккаунта. После этого используется обычный SendReactionRequest.

Пример:
https://t.me/c/3070674831/6029

Важно:
- аккаунт должен иметь доступ к этой приватной группе и сообщению;
- реакции должны быть разрешены в группе;
- файл не меняет авторизацию, список аккаунтов или интерфейс;
- если Telegram сам запрещает реакцию, Telethon вернёт ошибку, которую текущая
  панель покажет как результат аккаунта.

Установка:
1. Скачай ZIP.
2. Замени в проекте текущий telegram_actions.py на файл из ZIP.
3. Перезапусти приложение.
