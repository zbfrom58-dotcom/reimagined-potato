Патч интерфейса жалоб: несколько аккаунтов + очередь.

1. Распакуйте ZIP в корень проекта reimagined-potato.
2. Сделайте резервную копию web_panel.py и telegram_actions.py.
3. Запустите:
   python apply_report_queue_patch.py
4. Перезапустите userbot/web panel.

В интерфейсе:
- несколько аккаунтов выбираются чекбоксами;
- @username, причина и комментарий вводятся один раз;
- «Создать очередь» сохраняет данные;
- текущий аккаунт показывается сверху;
- «Отправить от ...» требует отдельного ручного нажатия;
- после отправки показывается следующий аккаунт;
- данные формы не нужно вводить заново.

Патч не делает автоматическую массовую отправку одной жалобы от всех выбранных аккаунтов.
