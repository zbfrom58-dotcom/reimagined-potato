Этот патч предназначен для zbfrom58-dotcom/reimagined-potato (main).

Что меняется:
- раздел «Жалобы» позволяет выбрать несколько аккаунтов;
- сохраняет username, причину и подпричину в сессии;
- создаёт очередь выбранных аккаунтов;
- отправка выполняется только отдельным ручным нажатием для текущего аккаунта;
- после отправки автоматически выбирается следующий аккаунт;
- история сохраняется по каждой отдельной ручной отправке.

Патч не добавляет автоматическую рассылку/таймер для жалоб.

Применение:
1. Скачай репозиторий.
2. В корне репозитория выполни:
   git apply web_panel_reports_queue.patch
3. Перезапусти приложение.
